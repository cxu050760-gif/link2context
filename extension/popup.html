Link2Context

只发链接 → 网页 AI 自动拿到内容 / Paste link → AI gets content

网页 AI 自动模式 / Auto mode

正在检测当前网站…

ChatGPT、豆包、Kimi、Claude、Gemini、DeepSeek、千问等已内置支持；其他网页 AI 可在这里一键启用。

上下文交付方式 / Context delivery

智能模式保持现有策略：例如 ChatGPT 对话优先 Markdown 文档，DeepSeek / 豆包等短内容优先长文本。

处理完成后的发送 / Send after handoff

手动确认：无论你是粘贴、按 Enter 还是点发送，Link2Context 都只把内容准备好并停在输入框里，由你检查后再发送。

授权浏览器上下文 / Authorized browser context 检测中…

开启后，当普通 Fetch（抓取）遇到 401 / 403，或 HTML 只有 JS 空壳时，Link2Context 可以自动在后台使用当前浏览器的 JavaScript 渲染、Session（会话）和 Cookie（登录状态）继续尝试。首次开启即视为持续授权，不会每个链接重复询问；使用时进度面板会明确显示。

关闭授权会立即阻止新的登录态回退；正在运行的任务可直接在右下角进度面板点 STOP / 停止。
