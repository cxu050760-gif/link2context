# Link2Context V0.6 Live Evidence / 真实浏览器证据

> 规则：CI / unit test（单元测试）只能证明代码契约；第三方网页 AI 的能力必须单独记录 live evidence（真实网页证据）。没有真实证据就写 `UNVERIFIED`，不得用“应该可以”代替。

## 证据状态

- `PASS`：真实浏览器已验证。
- `FAIL`：真实浏览器已复现失败。
- `UNVERIFIED`：V0.6 尚未真实验证。
- `BLOCKED`：因账号、权限、验证码或外部条件无法验证。

## V0.6 release gate

V0.6 可以成为 release candidate（发布候选）但不能标记 live-complete，直到至少满足：

1. ChatGPT / DeepSeek / 豆包 / 千问：普通网页手动文本交付真实 PASS；
2. 千问 V0.5.3 的“可编辑、可删除”回归继续 PASS；
3. 至少一个真实图文网页证明：正文 + 关键图片同时交给目标 AI，图片失败时不会静默自动发送；
4. PDF/图片等原始二进制 V0.5.3 路径不回归；
5. Auto-send 每个目标单独记录；未 PASS 的目标必须 fail-closed（失败时不假装成功），且不阻塞默认手动模式；
6. STOP 至少覆盖网络抓取、渲染等待、媒体下载、页面交付和发送等待。
